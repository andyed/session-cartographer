# Session Cartographer 0.10.0

Session Cartographer now supports **Google Antigravity** as a full concurrent provider alongside Claude Code, Codex, and Hermes — capturing live events, indexing transcripts, and replaying Antigravity sessions in the local Explorer and Flow map.

## What's new

- **Live Antigravity capture hooks (`hooks.json` + `antigravity-hook-bridge.cjs`):** Ships a plugin-root `hooks.json` and a zero-dependency Node bridge that translates Antigravity's camelCase lifecycle payloads and tool calls (`run_command`, `edit_file`, `write_file`, `replace_file_content`, `search_web`, `read_url_content`) into Cartographer's existing hooks and strict Antigravity JSON responses (`{"decision":"allow"}`, `{}`, `injectSteps`). Deduplicates mid-turn `PreInvocation` calls and logs `Stop` turn milestones while failing open safely.
- **Transcript indexing, resolution & pre-JSONL backfill:** Adds `scripts/antigravity-transcript-to-turns.awk` (`turn-antigravity-<session>-<idx>`), `scripts/antigravity-source.js` (read-only `conversation_summaries.db` workspace→project resolution, `--show`, and optional `--backfill` for older pre-JSONL conversations), and wires `CARTOGRAPHER_ANTIGRAVITY_TRANSCRIPTS_DIR` across `resolve-transcript.sh`, `retro-index.sh --provider antigravity`, `catch-up-transcripts.sh`, `cartographer-search.sh --transcript`, and `standup-silence.js` subagent folding.
- **Explorer & Flow map replay:** Authorizes Antigravity brain roots in `explorer/server/transcripts.js`, normalizes `USER_INPUT` / `PLANNER_RESPONSE` / `tool_calls` / `GENERIC` results (including `<USER_REQUEST>` envelope stripping, uncached+cached token totals, and file edit/read references) in the Transcript viewer and Memory Desk, and replays Antigravity sessions in `/flow`.

- **Reliable `get()` across in-place upgrades & pruned worktrees:** Fixes a silent failure where `rg` exited 2 when a running MCP server's CWD was deleted or replaced during an upgrade, making `get()` report valid served `evt-*` IDs as missing (`--get` now anchors to a live directory, ignores user `.gitignore`/rg config on explicit log files, and falls back to `grep` on `rg` exit > 1; `cartographer-mcp.js` also passes a verified live `cwd` to spawned children).

## Install

Download the unified archive and its matching SHA-256 checksum from the release assets below. The same archive supports Claude Code, Codex, and Antigravity. Follow the [installation guide](https://github.com/andyed/session-cartographer/blob/v0.10.0/docs/RELEASE_INSTALL.md) for your agent.
