# Session Cartographer 0.6.0

Version 0.6 turns Session Cartographer's accumulated work history into a safer
operational surface: it can propose an evidence-backed auto-mode trust map,
produce tightly scoped machine feeds, and capture Bash-driven edits that the
hook previously dropped.

## Highlights

- **`/trustmap`** derives `autoMode.environment` proposals from actual cross-agent
  usage, verifies repository visibility with `gh`, preserves entries authored by
  other tools, and refuses to overstate a thin corpus.
- **Reliable hook capture** strips leading `cd ... &&` hops before noise
  classification and recognizes Bash redirects, heredocs, `sed -i`, `tee`, and
  Python file writes as edits.
- **Bounded machine feeds** add JSONL search output and a summary-only feed that
  requires an explicit project allowlist and does not contaminate human recall
  telemetry.
- **A real social card** gives the Explorer complete Open Graph/Twitter metadata
  and a high-contrast 1200x630 preview of keyword + semantic retrieval merging
  through RRF.

The release archive is self-contained for both Codex and Claude Code. Full
implementation detail and known limitations are in [CHANGELOG.md](../../CHANGELOG.md).
