# Session Cartographer 0.4.1

This release repairs direct repository-marketplace installs and bundles the
cross-provider indexing and recall-measurement work completed since 0.4.0.

## Highlights

- Checkout installs are now self-contained. The marketplace source contains the
  search/index runtime, project registry, and Explorer that were previously
  present only in the GitHub release archive.
- Release archives and checkout marketplaces share one runtime assembly helper,
  with isolated Codex and Claude managed-cache smoke tests plus a main/PR CI
  guard to prevent drift.
- Derived PostCompact summaries retain explicit non-canonical provenance,
  credential redaction, deterministic IDs, and transcript catch-up.
- Recall telemetry now attributes result reuse to the exact search call and
  reports explicit-use hit rate and MRR.
- Documentation includes the cross-provider assessment and the verified
  NuggetIndex-inspired event-lifecycle roadmap.

## Upgrade

Existing event logs and indexes remain compatible; no data migration is
required. Download and extract `session-cartographer-0.4.1.tar.gz`, then
register and install the extracted marketplace with either or both agents.

For a checkout marketplace already registered locally:

```bash
# Codex
codex plugin marketplace upgrade session-cartographer
codex plugin add session-cartographer@session-cartographer

# Claude Code
claude plugin marketplace update session-cartographer
claude plugin update session-cartographer@session-cartographer --scope user
```

Start a fresh task/session after upgrading. Codex users should review changed
hook definitions again with `/hooks`.

## Verification

The release was checked with unit tests, source-marketplace and release-archive
managed-cache smoke tests, plugin validation, checksum verification, and live
recall from the installed Codex and Claude caches.
