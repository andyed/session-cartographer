# Session Cartographer 0.4.0

One memory plane for Claude Code and Codex. This release captures provider
provenance at ingestion, searches both histories by default, and lets either
agent recover the other's work.

## Highlights

- One self-contained release archive installs as a local marketplace in Claude
  Code, Codex, or both.
- Provider-neutral hooks share JSONL event logs without a global mode switch,
  so Claude and Codex can run concurrently.
- Separate Claude and Codex transcript adapters normalize both formats into the
  same turn model for Qdrant indexing and Explorer display.
- `/remember`, `/focus`, `/carto`, `/wrapup`, and `/investigate` ship in both
  plugin layouts.
- Raw transcript search scans both provider stores; results retain provider and
  transcript-path provenance.
- The release archive contains the search/index scripts and Explorer, so an
  installed plugin does not depend on the developer checkout.

## Install

Download and extract `session-cartographer-0.4.0.tar.gz`, then run the commands
for either or both agents from the extracted directory.

### Codex

```bash
codex plugin marketplace add "$PWD"
codex plugin add session-cartographer@session-cartographer
```

### Claude Code

```bash
claude plugin marketplace add "$PWD"
claude plugin install session-cartographer@session-cartographer
```

Start a new task/session after installation. Existing event logs and indexes
remain compatible; no data migration is required. Historical transcript
backfill can target `all`, `claude`, or `codex` with `retro-index.sh --provider`.
