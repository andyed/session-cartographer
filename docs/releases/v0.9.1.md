# Session Cartographer 0.9.1

This release adds **Milestone 1 (Read-Only Antigravity Support)** to the unified Session Cartographer plugin bundle, letting Google Antigravity search, orient on, inspect, and run peer standups across your shared Claude Code, Codex, and Hermes session history.

## What's new

- **Native Antigravity plugin & MCP server:** Ships `.antigravity-plugin/plugin.json` and plugin-root `mcp_config.json` (`${PLUGIN_ROOT}/scripts/cartographer-mcp.js`) alongside the existing Claude Code and Codex manifests. Antigravity discovers all 7 `cartographer` MCP tools (`recall`, `get`, `mark_used`, `thread`, `orient`, `facts`, `standup`) and bundled skills automatically.
- **Read-only capture boundary:** Intentionally omits a plugin-root `hooks.json` in this milestone so Antigravity does not write live hook capture rows yet; live hook capture (M2) and transcript indexing / Explorer viewer (M3) are tracked as follow-on milestones.
- **Antigravity session & provider attribution:** Extends the canonical session-ID chain with `ANTIGRAVITY_CONVERSATION_ID` across CLI, hooks, and MCP (`provider: "antigravity"` inferred from environment or MCP `clientInfo.name`).
- **Explorer provenance:** Adds `antigravity` to Explorer's `AgentBadge` (`#9ecbff`, verified ≥ 10.33:1 contrast across all four dark surfaces), Recall view, and Image Wall labels.
- **Hermetic test harnesses:** Scrubs `ANTIGRAVITY_CONVERSATION_ID` and `ANTIGRAVITY_AGENT` across unit, browser, and packaging smoke suites so tests run cleanly inside live Antigravity sessions.

## Install

Download the unified archive and its matching SHA-256 checksum from the release assets below. The same archive supports Claude Code, Codex, and Antigravity. Follow the [installation guide](https://github.com/andyed/session-cartographer/blob/v0.9.1/docs/RELEASE_INSTALL.md) for your agent.
