# Session Cartographer 0.7.6

This release combines the local 0.7.5 development work with the working-memory
Explorer and release-readiness fixes. The previous public release was 0.7.4.

## Working memory

- Open `/memory` for Field, Wake, and Compare views of recorded sessions across
  projects. Compare duration, activity, generated or processed tokens, edits,
  research, and commits.
- Select a session to inspect activity and token traces, observations, and
  recently edited files. File review shows the current file and Git diff from
  HEAD; it is not a historical file snapshot.
- Session and file links preserve the view, axes, review mode, and replay
  window. Reload and browser history restore the selection, and older sessions
  reopen their last recorded window.
- Start the UI with `npm run memory` from Explorer. The page can enable, start,
  or refresh the shared managed Turbo service. Opening it alone changes no
  preference and starts no backend. Internals remains available on the UI host
  while Turbo is stopped.

## Recall and ownership

- The warm backend now separates ranked recall from counted facts: census,
  tempo, and log-position delta queries carry supporting event IDs.
- Recall applies time windows before truncation and uses consistent project
  scope across keyword and semantic sources. The pulse uses counted facts above
  its relevance feed.
- Git backfill imports configured owners by default. Full names remain one
  author pattern; empty explicit overrides are rejected. `--all-authors` remains
  an explicit option. Existing imported history is not rewritten by this update.
- Project aliases can live in a user-owned registry that replaces the shipped
  defaults. Adoption instructions now describe the actual lookup order.

## Installation and verification

The archive is one local marketplace for Claude Code and Codex. Follow its
README for installation and restart the agent client afterward. If a detached
Turbo service is already running, refresh it through the managed controller or
the memory page; restarting the client alone does not refresh that process.

Release metadata, including the root lockfile, is checked before packaging.
Publication requires Node 22 unit tests, the Explorer build and Chromium flow,
and the package smoke test. Managed CLI install checks run when those CLIs are
available; hosted CI does not establish a local managed-install result.

Turbo remains optional and experimental. Missing or partial transcript usage is
labelled, and the utility canary has not established better recall than the
portable backend.
