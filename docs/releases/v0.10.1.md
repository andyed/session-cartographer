# Session Cartographer 0.10.1

Claude Code, Codex, and Google Antigravity can now leave each other short notes while working on the same machine. If one session lands a change underneath another, it can tell the other session which file to re-read.

Use `standup` to find the recipient, then call `tell` with its session ID and your note. Standup shows how many notes are waiting. Claude Code and Codex receive a note on their next prompt. Antigravity can receive one at its next model invocation. Cartographer records both sending and delivery in the shared history.

**Upgrading Codex:** Approve the new delivery hook in the Codex CLI’s `/hooks` screen, then start a fresh chat. **Sending from Antigravity:** Use the bundled shell sender when you want a reply. It includes the conversation ID supplied by Antigravity.

Download the unified archive and matching SHA-256 checksum below. [Install and try messaging](https://github.com/andyed/session-cartographer/blob/v0.10.1/docs/RELEASE_INSTALL.md#send-a-note-to-another-session).
