# Session Cartographer 0.8.4

Fixes Windows hook execution that could repeatedly open the system's “choose an app to open this .sh file” dialog. Session-end events, including archiving a Codex chat, could trigger it as well as ordinary hook activity. This was observed on Windows 11 with Codex; the defect is in shared plugin registrations, not a machine-specific file association.

## Hook launcher

Both providers now invoke a Node launcher, which passes the shell script as an argument to an explicit Bash executable. On Windows it locates Git for Windows, uses no shell association, and hides the child window. An absolute CARTOGRAPHER_BASH executable path can override discovery. Missing Bash fails with a short diagnostic and no retry.

The launcher preserves stdin, output, and ordinary hook exit status. It suppresses recursive launches, allows at most eight active hooks per user, and terminates a timed-out child tree. Session-end hooks use a two-second execution budget and cleanup capped at half a second within Codex's three-second cap. Launcher failures pause hooks for 30 seconds rather than repeatedly spawning failures. Saturated or paused hooks may skip events; the launcher does not queue work. Existing transcript catch-up can recover transcript history later.

Shell scripts and awk sources check out with LF on Windows. A Windows CI job covers the actual registered SessionEnd command through PowerShell, Unicode and spaced paths, stdin, exit status, concurrency, and descendant cleanup. Release publication depends on that Windows job as well as the existing Explorer gate.

## Other fixes included since 0.8.3

- Codex prompt ingestion understands the item_completed UserMessage format.
- Transcript catch-up can reclaim a lock left by a killed run.
- Index request bodies reach curl over stdin, preserving non-ASCII text on Windows.
- Session start reports missing jq instead of silently leaving capture unavailable.
- Memory backfill uses a portable UTC file timestamp.
- The release builder passes native paths as arguments and uses Node for SHA-256, so it also runs on Windows without shasum.

## Improvements already merged on main

This release also includes the intervening main-branch work: safer concurrent JSONL writes and rewrite locks, indexed-history lookup and fetch corrections, a text-only MCP interface, optional prompt recall and first-edit history context, Hermes dashboard conversation support, and loopback/Qdrant authentication hardening. The [changelog](../../CHANGELOG.md) records those changes and their validation.

## Recovery and upgrade

If app-picker dialogs are appearing, disable Session Cartographer and fully quit the affected agent app before updating. Disabling a plugin in saved settings may leave registrations held by an already-running session. Close stray app-picker windows; do not associate .sh files with a different application as a workaround.

Update the plugin in each agent, restart the app, and review the changed hook commands in Codex's hook approval UI. Do not copy or alter existing approval hashes. The new commands begin with node and invoke run-hook.cjs; a hook command starting directly with a .sh path is still the old configuration.
