# Session Cartographer 0.9.0

Session Cartographer gives Claude Code and Codex a shared local memory of your work. Ask one agent why you made a decision with the other, and it can recover the reasoning, the technical details, and the conversation they came from.

## New in the Explorer

The Flow map follows a session through its model steps, file edits, shell commands, memory calls and messages. Open `/flow` in the local Explorer and select a Claude Code or Codex session. Scrub to a moment to see which stations it used and how full its context window was. The center node keeps the percentage visible on narrow maps. Claude Code’s desktop app also offers a live pane beside the chat through `/carto-flow`.

The Flow map grew from [lot-map](https://github.com/alexeyw/lot-map) by Aleksei Volodin. See the [Flow map guide](https://github.com/andyed/session-cartographer/blob/v0.9.0/docs/FLOW_MAP.md) for the replay controls, pane options and desktop support.

## Also included

- Replay and search archived, zstd-compressed Codex rollouts, including sessions recorded on Windows.
- Review long files in the Memory Desk by page or line, search within a file and open it in an editor.
- Browse session images in the Explorer and read unresolved work from a session’s wrapup.

Download the marketplace archive and its matching SHA-256 checksum from the release assets. The same archive supports Claude Code and Codex. Follow the [installation guide](https://github.com/andyed/session-cartographer/blob/v0.9.0/docs/RELEASE_INSTALL.md) to register the extracted directory and start the optional local Explorer.
