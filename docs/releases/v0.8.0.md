# Session Cartographer 0.8.0

This release retires `/focus`, whose orientation moves into `/remember`. It
brings Hermes Agent into the corpus, warns before two sessions edit the same
file, and makes Turbo both easier to turn on and slower to give up. Most of the
remaining changes fix places where events went missing, carried the wrong type,
or were credited to the wrong session, without anything reporting an error.

## `/focus` is now `/remember --project` (breaking)

- Claude Code 2.1.269 ships a built-in `/focus` view, which shadows this
  plugin's skill of the same name. Orient on a project by giving `/remember` a
  project and no question:

  ```text
  /remember --project <name>
  ```

  It runs the same recency search plus the related-threads and recurring-maneuvers
  lenses `/focus` did.
- `skills/focus` stays as a pointer for this release, so older instructions and
  other agents are redirected rather than broken. Update any custom instructions
  that still say `/focus`.
- `CARTOGRAPHER_FOCUS_ON_START` keeps its name.

## Hermes Agent

- Hermes sessions and configured workspace notes can now enter the corpus, where
  search, facts and `/standup` see them and the Explorer marks them with a
  `hermes` badge. The adapter reads every Hermes profile's `state.db` read-only and does
  nothing until you write a policy file:

  ```bash
  node plugins/session-cartographer/scripts/hermes-source.js --print-config-path
  node plugins/session-cartographer/scripts/hermes-source.js          # dry run: counts only
  node plugins/session-cartographer/scripts/hermes-source.js --write
  ```

  The policy can drop whole sessions by project or path and redact matching
  lines. Cron prompts and tool results are never indexed. Once a policy exists,
  the session-start catch-up runs the adapter for you. `--show <session>`
  prints one session's turns, since Hermes keeps no transcript file.
- Recall calls made from Hermes now say they came from Hermes. To record which
  Hermes session made them, have the wrapper Hermes runs export the session
  itself. See "Recall telemetry from Hermes" in [SETUP.md](../SETUP.md).

## Turbo

- `/carto` now turns Turbo on for you on machines with 16 GB or more of RAM,
  when Turbo's estimated memory use is within 8% of it. Elsewhere it reports the
  estimate and changes nothing. Below 16 GB, a running service exits after 30 idle minutes
  (`turbo.idle_minutes` overrides this). `status` shows the memory plan.
- A slow recall now falls back to the portable search once, instead of being
  run a second time first. The default wait before falling back rises from
  1.5 s to 4 s, which covers the slowest searches measured. Configs written by
  an earlier `/turbo enable` keep 1.5 s until you raise it:

  ```bash
  node plugins/session-cartographer/scripts/cartographer-turbo.js enable --timeout 4000 --no-start
  ```

- A running service now answers the same as a freshly restarted one. It no
  longer misses events written while it was starting or written in two parts,
  and it merges an event logged twice instead of keeping only the first copy.
- `status` checks that the service is still following your logs, not just that
  it is running. It reports `index_freshness` as `live`, `stale` or
  `unverified`, with details for each log.
- When Turbo fails to start, `server.log` now says whether it was stopped at
  the start deadline or exited first. `CARTOGRAPHER_TURBO_READY_TIMEOUT_MS`
  changes the deadline.

## Collision warning before an edit

- Before Claude Code or Codex edits a file, a new hook checks whether another
  session edited or committed that file in the last 45 minutes. If so, it tells
  the agent whether the other session is in the same checkout (a commit here
  could sweep up its uncommitted changes) or a separate worktree (the conflict
  arrives at merge). It never blocks, and stays silent otherwise. Turn it off
  with `CARTOGRAPHER_COLLISION_CHECK=0`.

## Memory Desk (alpha)

- A new **Recall** view lists every `/remember` call in the window, grouped by
  session, with each call's ranked results. Results an agent marked with
  `--touch` show as "marked used" at the rank where they were served. Calls with
  no session are grouped as **Unattributed** rather than hidden.
- `/wrapup` notes and Hermes runs are now typed as what they are, not as generic
  `milestones`, so a session's wrapup appears among its outcomes and the type
  filter lists each kind.
- In the full-size Activity view, the Field readout no longer hides its first
  line under the header or covers the point it describes.

## Event capture

- Commits are recorded when made with `git -C <repo>` or `git -c`, when
  `git commit` comes after the first 500 characters of the command (for example
  after a long message written with `cat > file <<EOF`), and when the command
  starts with `cat`. Before, these were logged as ordinary commands or dropped,
  and `/wrapup` showed no commits.
- A command line is no longer dropped as noise because its first command is
  `cat` or `echo`: each part is judged on its own. Expect up to about 22% more
  command rows in `tool-use-log.jsonl`.
- Commits by other people in repositories you cloned no longer count as your
  session's work in search, digests, `/standup` or the profile. To fix rows
  written before this release (a dry run unless you pass `--apply`, which keeps
  a backup):

  ```bash
  node plugins/session-cartographer/scripts/repair-foreign-commit-sessions.js
  node plugins/session-cartographer/scripts/repair-foreign-commit-sessions.js --apply
  ```

## Search

- The portable search now reads text after an escaped quote in a log entry.
  More than a quarter of summaries, mostly commands with quoted arguments, were
  partly invisible to `/remember` with Turbo off.
- The portable search honours `CARTOGRAPHER_SEMANTIC=0`.
- The Explorer's search returns no results instead of an error for a query with
  no searchable words, such as punctuation only.
- The facts `delta` verb describes an event the same way `census` does.

## Recall telemetry

- Every served, search-call and access row now records where its session came
  from (`session_source`). Served and search-call rows say `no_session` when
  there was none, instead of leaving the field empty. A session value of
  `unknown` is treated as no session rather than as an identity.

## Explorer readability

- Text across the Timeline, Sessions, Search, the search box and the Transcript
  viewer now meets an 8:1 contrast floor. Badges and filter pills are outlined
  in a single set of hues, and in the search suggestions the completed part of
  each option is set in bold.

## Upgrading

Update the plugin in every agent you use, then start a new session:

```bash
claude plugin update session-cartographer@session-cartographer --scope user
codex plugin add session-cartographer@session-cartographer
```

Then, if they apply to you:

- Replace `/focus` in any custom instructions with `/remember --project <name>`.
- Raise a Turbo config written before this release to the 4 s wait (see Turbo
  above).
- Codex will ask you to review the changed hooks in `/hooks`. This release adds
  the pre-edit hook.
- Run the foreign-commit repair once if you import git history from repositories
  other people commit to.

Update Claude Code and Codex together if you use Turbo. They share one
background server, and the first recall after an update replaces a server from
a different version, so two versions would keep replacing each other. Paths
above are relative to the extracted release archive or a source checkout.
