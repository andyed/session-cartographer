# Session Cartographer 0.7.7

A check-in release over 0.7.6: the architecture diagram is regenerated from the
code it describes, recall performance is measured end to end with a repeatable
script, and the two defects that measurement found are fixed. The Explorer's
memory work desk introduced in 0.7.6 remains **very alpha** — its layout, axes,
and URLs are still moving between releases — and is unchanged here.

## Performance check-in

- `scripts/perf-checkin.js` measures the in-process folds and scorers, the
  portable bash + awk CLI, and the managed Turbo service through its real
  controller, then probes Turbo's failure modes: twenty concurrent recalls, a
  contract rejection, malformed JSON, a live append reaching the warm index
  without a restart, and a clean stop. Every check asserts on composition —
  counts reconcile to an independent scan — not on "results came back".
  Results and interpretation are in `docs/perf-checkin-2026-09-14.md`.
- `tempo` formatted a day string once per event; it now formats once per
  distinct day with byte-identical output. Tempo over 127k events dropped from
  168 ms to 87 ms on the same machine.
- `cartographer-turbo.js enable` could return while the HTTP port was still
  opening, so a recall fired immediately afterwards raced the listener and
  succeeded only through the file spool. The controller now waits for a
  terminal HTTP state.
- Turbo held up under everything else the probe tried: no failures in a burst
  of twenty concurrent recalls, a contract rejection answered in under 2 ms with
  the client exiting non-zero in about 100 ms and no spool fallback, a live
  append recallable within about 150 ms, and `disable` leaving no process or
  state file behind. Turbo stays opt-in and experimental; the utility canary in
  `docs/TURBO_MODE_SPEC.md` is unchanged.
- `tests/unit/facts-performance-guardrails.test.js` bounds census, tempo, and a
  delta resume and requires their counts to reconcile to the fixture, closing
  the regression-test gap FACTS.md recorded.

## Architecture diagram

- `diagrams/build-architecture.mjs` regenerates `architecture.png`, an SVG, and
  the editable `.excalidraw` from one layout spec. The diagram now shows both
  agents, all five searched logs, the transcript and optional Qdrant stores, and
  the lenses that ship, with the memory desk marked very alpha and Turbo marked
  opt-in and experimental.

## Installation and verification

The archive is one local marketplace for Claude Code and Codex. Follow its
README for installation and restart the agent client afterward. If a detached
Turbo service is already running, refresh it through the managed controller or
the memory page; restarting the client alone does not refresh that process.

Release metadata, including the root lockfile, is checked before packaging.
Publication requires Node 22 unit tests, the Explorer build and Chromium flow,
and the package smoke test.
