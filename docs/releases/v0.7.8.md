# Session Cartographer 0.7.8

This release brings Codex's curated memory into Cartographer recall and improves
the evidence behind `/standup`. It also includes the managed Turbo server lease
fix recorded in the changelog. The previous public release was 0.7.7.

## Codex memory

- Import the native Codex memory registry, overview, and rollout summaries as
  versioned events. Source files are read only. A repeat import appends only
  changed or removed entries.
- CLI and Explorer/Turbo search suppress superseded events before ranking.
  Current Codex user preferences can contribute to the standing profile.
- Keyword recall needs no service. Semantic recall is refreshed explicitly with
  `--index` when Qdrant and the embedding server are available. Import remains
  on demand; it does not watch Codex memory files.
- Existing users should follow the [migration guide](../MIGRATION_CODEX_MEMORY.md)
  after updating their installed plugin copy. Refresh a running Turbo process
  separately from restarting the client.

## Standup

- `--commit` applies its requested time window. `--project` retains file edits
  recorded under the workspace-root project label.
- Verified Codex worktrees and their main checkout now resolve to the same file
  for contention. An unverifiable worktree is counted as unmapped instead of
  being paired by a similar directory name.
- Display labels expand when session IDs share an eight-character prefix.
  Activity markers reflect event recency, not process liveness. Shared-goal
  coordination is documented as a future design, not a shipped feature.

## Turbo and installation

The managed Turbo server now exits when its ready-file lease disappears, and
the controller reaps a child that fails to become ready. The unified archive
installs for Claude Code and Codex. Follow the archive README for installation,
fresh-session and hook-review steps. Publication and managed-install verification
are separate from building the archive.
